# Plotus

**Make room for your next idea.**

Plotus is a home-planning workspace for architects and residential designers. It is being built to turn plot details and a client's brief into floor-plan concepts that can be reviewed before detailed design begins.

## The idea

A home starts with more than room dimensions. There is a site, a family, a budget and a way of living. Plotus aims to bring those decisions together so designers can spend less time piecing together project context and more time shaping the home.

The intended journey is simple:

1. **Start a project** with its location and client details.
2. **Understand the plot** — its boundaries, road access, orientation and setbacks.
3. **Define the home** — floors, rooms and the client's priorities.
4. **Review a concept** and refine it with the client.

## Try the demo

The current iPhone and web demo lets you explore projects, add or edit project and client details, search and sort your work, and switch between light and dark themes.

Choose **View demo** on the welcome screen. Project changes last for the current demo session. Google sign-in is available on iPhone and web. Web accounts can also add a passkey. Saved projects and floor-plan generation are still in development.
